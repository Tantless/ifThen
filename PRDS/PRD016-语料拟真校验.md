# PRD016-语料拟真校验

## prd-语料拟真校验-完成情况

### 目标

为 `tests/fixtures/realism_synthetic` 三段合成聊天记录补上可执行的真实性校验层，先把已识别的 AI 味问题转成稳定 audit 合同，再为后续重生成或局部改写提供防回归机制。

### 需求

- 新增可运行的合成语料真实性校验入口，覆盖导出时间、时间语义、未来证据边界和过度重复线索。
- 当前已知语料缺陷不得被静默忽略；必须以显式 waiver 记录，并在测试中保持可见。
- 修复低风险且不会破坏 baseline target 的明显错误。
- 保留三段语料的可解析性、baseline 锚点和 performance runner 输入形态。

### 验收标准

- 校验入口能遍历 `tests/fixtures/realism_synthetic` 并输出结构化报告。
- 当前测试集没有未豁免的真实性校验失败。
- 已知未改写问题被稳定记录为 waived finding，后续新增同类问题会导致测试失败。
- 相关生成脚本或文档说明后续语料生成必须经过真实性校验。

### 当前完成情况

已完成。

## 工作记录及完成情况

- 新增 `scripts/validate_realism_synthetic_corpus.py`，遍历 `tests/fixtures/realism_synthetic` 并输出结构化 JSON 报告，当前覆盖导出时间不得早于最后消息、下午/晚上不得出现“今天上午”类强时段冲突、20:00 前 `快睡` 语义风险、future evidence 提前出现和过度重复线索。
- 当前三段语料仍存在 3 个已知拟真性债务，已用显式 waiver 记录：case-01 `别对我太好` 过度重复、case-02 家庭检查信息早于 `truth-after-cutoff` 揭示、case-03 baseline 绑定的 19:23 `快睡` 目标句。
- 修复低风险语料错误：将 case-01 `导出时间` 调整为晚于最后消息，将 case-02 晚间 `今天先撑过上午` 改为 `今晚先撑过这一阵`。
- 更新 `scripts/generate_realism_synthetic_corpus.py`，后续生成时会避免强时段词和 chunk 时间范围冲突，并在渲染 QQChatExporter header 时自动保证 `导出时间` 不早于最后消息。
- 更新 `tests/test_realism_synthetic_fixtures.py`，把 synthetic corpus audit 接入 pytest，要求当前没有未豁免 finding，并验证新增未豁免的时间缺陷会导致报告失败。
- 更新 rollout/roadmap 文档，将 `PYTHONPATH=src python scripts/validate_realism_synthetic_corpus.py` 纳入真实性变更的必跑质量检查。
