# PRD015-头像生图脚本

## prd-头像生图脚本-完成情况

### 背景

当前目录已经有头像素材与单独的 `image_model.env`，需要一个尽量小的 Python 脚本，直接读取该配置并通过 Responses API 批量生成头像。

### 目标

提供一个最小可改、可批量、可直接运行的头像生图脚本，并验证真实请求链路。

### 需求

- 读取 `desktop/public/avatars/image_model.env`。
- 使用 Responses API 进行图像生成。
- 支持从单独提示词文件批量读取 prompt。
- 将生成结果保存到当前目录下的新输出文件夹。
- 运行一次真实 smoke test，确认当前配置是否可用，并记录结果。

### 验收标准

- [x] 新增最小 Python 脚本，默认从 env 和 prompts 文件读取配置。
- [x] 脚本支持批量输出到独立目录。
- [x] 已执行真实请求验证并记录结果。
- [ ] 完成 git commit。

## 工作记录及完成情况

- 新增 `desktop/public/avatars/generate_avatars_responses.py`，使用 `openai` Python SDK 调用 `client.responses.create(...)`，通过 `image_generation` 工具生成图片并把 base64 结果写入本地文件。
- 新增 `desktop/public/avatars/avatar_prompts.txt` 作为最小批量提示词入口，每行一个 prompt。
- 保留 `image_model.env` 中的 `IMAGE_MODEL_NAME` 作为图像模型配置，同时在脚本中单独提供 `RESPONSE_MODEL_NAME`，因为 Responses API 的顶层 `model` 需要是可调用工具的响应模型，而不是直接填图像模型。
- 已用 `image_model.env` 真实发起 smoke test，请求被上游网关返回 `403 Your request was blocked.`，说明当前阻塞点在 provider / 网关权限，而不是本地脚本结构。
