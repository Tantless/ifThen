## prd-检索排序预算-已确认

### Goal

在 `realism-02` 的分层证据合同基础上，实现第一版检索排序与上下文预算，让 context pack 在固定预算内优先保留高相关、高约束证据。

### Requirements

- 为 `related_topic_digests` 和 `future_evidence_digests` 增加确定性排序，首版信号包含：目标段 topic 重合、敏感度、时间接近度、稳定性。
- 为 `current_segment_history`、`same_day_prior_segments`、`related_topic_digests`、`future_evidence_digests` 定义显式预算并在装配时执行。
- 输出 `retrieval_trace` 与 `retrieval_budget`，记录预算、选中项和主要命中原因。
- 没有 topic link 时，仍保留时间邻近段和 cutoff-safe snapshot 作为退化路径。
- 保持现有 simulation / realtime branch 路径兼容，不修改 prompt 合同，不引入 future leakage。

### Acceptance Criteria

- `related_topic_digests` / `future_evidence_digests` 数量受预算限制。
- 敏感且同 topic 的 future 证据优先于无关 future 闲聊。
- `context_pack` 包含可解释的 `retrieval_trace` 与 `retrieval_budget`。
- 没有 topic link 时，context pack 仍保留 `same_day_prior_segments` 与 `base_relationship_snapshot`。
- `PYTHONPATH=src pytest tests/test_retrieval.py tests/test_simulations.py -q` 与 `PYTHONPATH=src pytest -q` 通过。
