# PRD017-背景事实

## prd-背景事实-完成情况

### 目标

为实时反事实分支新增“人物彼时现实背景”上下文层，让 LLM 在生成 `other` 回复时知道角色当时的现实处境、正在做什么和可能正在想什么，从而在用户改写命中真实状态时做出自然反应，同时避免把后文证据当成台词来源泄漏。

### 需求

- 新增 `objective_moment_facts` 上下文层，来源限定为目标消息附近的原时间线窗口。
- 该层语义是背景参考，不是 cutoff-safe 聊天事实，也不是普通 future evidence。
- 背景事实可影响 `other` 的处境理解、注意力和反应强度，但不得被复述、引用或解释来源。
- 继续保留 future evidence 的 modeler-only 泄漏护栏，拒绝、关系结论、后续偏好等事实不得进入角色台词。

### 验收标准

- context pack、session memory pack 和 realtime branch prompt 均包含 `objective_moment_facts`。
- 动漫类样例能提供 `other` 正在看动漫的背景事实，并提示 LLM 只能作为背景使用。
- future evidence 泄漏回归仍通过，后续拒绝/边界证据仍标记为 modeler-only。
- 后端定向测试和完整 pytest 通过。
