# PRD013-数据集配置

## prd-数据集配置-完成情况

### 背景

真实性路线图的测试数据集应定位到仓库内合成测试集 `D:\ifThen\tests\fixtures\realism_synthetic`，而不是旧外部聊天文件。同时，本项目已有本地 `llm_config.env`，provider 回归应优先读取该 env 文件，并通过 Responses API 的 JSON object 输出格式请求 LLM。

### 目标

修正路线图、rollout、PRD 和 trace 记忆中的测试集定位，并让 provider 回归运行器支持从 `llm_config.env` 读取配置执行真实 LLM 验证。

### 需求

- 统一将真实性验证测试集描述为 `D:\ifThen\tests\fixtures\realism_synthetic`。
- 不再把外部 5000 条聊天文件作为当前 realism 测试集或阻塞条件。
- `scripts/run_realism_provider_regression.py` 默认读取 `llm_config.env`。
- env 文件配置键支持 `API_BASE_URL`、`API_KEY`、`MODEL_NAME`。
- 使用 Responses API 的 `text.format.type = json_object` 请求结构化输出。
- 增加自动化测试覆盖 env 加载、Responses API 解析和报告中不泄漏密钥。

### 验收标准

- [x] 路线图和 rollout 文档均指向仓库内合成真实性测试集。
- [x] provider 回归脚本支持本地 env 文件和 Responses API。
- [x] 相关后端测试通过。
- [x] 完成 git commit。
